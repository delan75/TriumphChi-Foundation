# Public Identifiers

API-facing domain records use UUIDs as route keys. Numeric primary keys remain internal database identifiers for joins, indexes, and foreign keys.

The affected records are:

- applications
- beneficiaries
- schools
- donors
- funds
- donations
- educational needs
- allocations
- payments
- sponsorships
- impact updates

Resources expose `uuid` so clients can build URLs without using database IDs.

## Reference Numbers

Custom business references are generated by the backend when not supplied:

- `APP` for applications
- `BEN` for beneficiaries
- `DON` for donations
- `ALL` for allocations
- `PAY` for payments
- `SPN` for sponsorships

The format starts with a period code:

```text
2 + last two digits of year + month code
```

Examples:

- July 2017: `2177`
- February 2018: `2182`
- January 2022: `2221`
- May 2026: `2265`
- October 2026: `226A`

Random uppercase characters follow the period code. This keeps references unique and searchable by period without making them sequential or guessable.
